# Papéis da Equipe

Papéis internos do trabalho acadêmico. Preencham a coluna de responsável com os nomes dos integrantes antes do fim da Sprint 1.

| Papel | Responsabilidade | Responsável |
| --- | --- | --- |
| Coordenação | Mantém o backlog no Boards, conduz as cerimônias e responde pela entrega no prazo | |
| Diagnóstico | Caracterização da organização, stakeholders e práticas atuais | |
| Modelagem de processo | Ciclo de vida, fases, atividades e diagramas | |
| Artefatos e customização | Catálogo de artefatos, templates, categorias e matriz de customização | |
| Qualidade e rastreabilidade | Revisão cruzada das páginas e manutenção da matriz de rastreabilidade | |
| Documentação | Padrão da Wiki, navegação, links e consolidação final | |

Todo integrante revisa ao menos uma página escrita por outro, conforme a definição de pronto do [Termo de Abertura](./Termo-de-Abertura.md).
