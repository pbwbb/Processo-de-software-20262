# Retrospectivas

Uma seção por Sprint, preenchida no encerramento. O registro alimenta a revisão de coerência da Sprint 3.

## Modelo

| Campo | Conteúdo |
| --- | --- |
| O que funcionou | Práticas que a equipe quer manter |
| O que atrapalhou | Obstáculos concretos, com exemplo |
| Decisões tomadas | Mudanças acordadas para a Sprint seguinte |
| Ação de melhoria | Uma ação com responsável e prazo |
