# Glossário

## Domínio da organização

| Termo | Significado |
| --- | --- |
| ANS | Agência Nacional de Saúde Suplementar, reguladora do setor de planos de saúde no Brasil |
| ANPD | Autoridade Nacional de Proteção de Dados |
| Glosa | Recusa total ou parcial do pagamento de um procedimento pela operadora |
| LGPD | Lei Geral de Proteção de Dados, que trata dado de saúde como dado pessoal sensível |
| Operadora | Empresa que comercializa e administra planos de saúde |
| Prontuário eletrônico | Registro clínico do paciente em meio digital |
| Saúde suplementar | Setor privado de assistência à saúde, complementar ao sistema público |
| TISS | Troca de Informação em Saúde Suplementar, padrão da ANS para comunicação entre prestadores e operadoras |

## Processo e engenharia de software

| Termo | Significado |
| --- | --- |
| Artefato | Produto de trabalho consumido ou gerado por uma atividade do processo |
| ASVS | Application Security Verification Standard, padrão da OWASP com requisitos de segurança por nível |
| Categoria de projeto | Classe de demanda que determina quais elementos do processo se aplicam |
| Customização | Adaptação justificada do processo padrão a uma categoria ou a um caso específico |
| Definição de pronto | Conjunto de condições que um item precisa atender para ser considerado concluído |
| Definição de preparado | Conjunto de condições que um item precisa atender para entrar em uma iteração |
| Desvio | Dispensa registrada e aprovada de um elemento obrigatório do processo |
| DevOps | Conjunto de práticas que integra desenvolvimento e operação, apoiado em automação |
| Gate | Marco de aprovação com critérios objetivos de entrada e de saída entre fases |
| Incremento | Resultado funcional e testado produzido ao fim de uma iteração |
| ITIL | Conjunto de boas práticas de gerenciamento de serviços de TI |
| Kanban | Método de fluxo contínuo com visualização do trabalho e limite de trabalho em progresso |
| Lead time | Tempo entre a entrada de uma demanda e a sua entrega |
| MPS.BR | Melhoria de Processo do Software Brasileiro, modelo nacional de maturidade |
| OWASP SAMM | Software Assurance Maturity Model, modelo de maturidade em segurança de software |
| Processo Unificado | Processo iterativo organizado em concepção, elaboração, construção e transição |
| RACI | Matriz que distingue quem executa, quem responde, quem é consultado e quem é informado |
| Rastreabilidade | Ligação verificável entre origem da demanda, requisito, implementação e teste |
| Scrum | Framework ágil baseado em iterações de duração fixa com papéis e cerimônias definidos |
| SLA | Acordo de nível de serviço, com prazo máximo de atendimento por prioridade |
| Squad | Equipe multidisciplinar responsável por um conjunto de funcionalidades |
| Sustentação | Atendimento de correções e pequenas evoluções em sistemas já em operação |
| Trabalho em progresso | Quantidade de itens iniciados e ainda não concluídos em um fluxo |
